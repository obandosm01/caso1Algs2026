## Instrucciones para ejecutar el proyecto si fuera necesario:
0. Instalar Go: Este proyecto está programado en su totalidad en Golang, entonces se debe instalar antes de poder ejecutar el proyecto. Se puede usar [este link](https://go.dev/doc/install). 
1. Clonar el repositorio:
```bash
git clone https://github.com/obandosm01/caso1Algs2026.git
cd caso1Algs2026
```
2. Instalar las dependencias: Para que el proyecto funcione, deben instalarse las dependencias necesarias. Por fortuna, Go ofrece un comando que instala automaticamente todas las dependencias del proyecto.
```bash
go mod tidy
```
3. Crear la carpeta "resultados" en la raíz del proyecto.
```bash
mkdir resultados
```
4. Ejecutar el proyecto
```
go run main.go
```
Nota adicional: La duración de ejecución de cada algoritmo está hardcodeada en el main en la variable `tiempoEvaluacionSegundos`.
